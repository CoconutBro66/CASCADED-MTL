# CASCADED-MTL


## Install Dependencies
Create a conda environment using the provided .yaml file.

## Source Code Structure
完整实验可按文件夹名中的序号进行，也可以选择执行脚本
<div>
  
| # | Description |

### Running the Experiments
各代码可在上述环境中直接运行，只需要更改模型及数据路径。
代码运行结束后会保存相应的测试集评估结果。
